# LocalSber project rules

For first-run Orca and agent configuration, see [setup.md](setup.md).

- Work from the LocalSber workspace root and check for more specific instructions in the directories you edit.
- Keep changes scoped to the task and preserve existing user changes.
- Use the project's documented setup, build, and test commands once they are available. Run the checks relevant to the change and report any checks you could not run.
- Keep credentials and machine-specific settings out of shared project files.
- Review the affected files before handoff and summarize what changed and how it was verified.
